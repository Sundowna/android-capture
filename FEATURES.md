# Feature inventory (regression checklist)

For coding agents. Read this before rebuilding, redesigning or replacing any screen or module of the Brain app (playground build: Brain Play).

How these features connect, step by step: [FLOWS.md](FLOWS.md). How to test all of it end to end on the phone: [E2E-TESTS.md](E2E-TESTS.md). How it is built (rebuild handover): [SPEC.md](SPEC.md).

## Rule

1. Before the change: mark which items below the change touches. Re-read their code; this list can lag.
2. After the change: check each touched item on the phone, not only in code. Check stateful controls in every state (idle, recording, paused, busy, private, no AI model).
3. Fix anything missing before reporting the work as done.
4. Never drop a listed feature silently. If an item cannot or should not be kept, report one line each:
   `Dropped/changed: <what> | why: <reason> | impact: <what the user loses>`
   Ask before dropping anything the user interacts with directly.
5. New or changed feature: update this file and its test in E2E-TESTS.md in the same change.

Source: read from `app/src/main` (branch `playground`, 2026-11-21; main has the same features, see section 17), README.md and docs/*.md. File names are under `app/src/main/java/org/brain/capture/` unless stated.

## 3. Recording

- [ ] Foreground service owns the mic; recording and processing are independent: a new recording can start while earlier ones are transcribed; recordings queue, oldest first (`audio/CaptureService.kt`)
- [ ] 16 kHz mono 16-bit, voice-recognition mic source, written to app storage `files/staging/<yyyy-MM-dd_HHmmss>.wav`, synced to disk every second (`audio/CaptureService.kt`)
- [ ] Database row exists from the first second, so an interrupted recording and its target note are never forgotten (`audio/CaptureService.kt`)
- [ ] Pause keeps the mic open but writes nothing; paused time is left out of audio and timer (`audio/CaptureService.kt`)
- [ ] Discard deletes the audio and forgets the row (`audio/CaptureService.kt`)
- [ ] Vibration tick on start, stop, pause/resume and discard (`audio/CaptureService.kt`)
- [ ] Storage: refuses to start below 50 MB free ("Phone storage is full…"); warns with minutes left when under about 1 hour; stops and keeps the recording below 20 MB, with a warning on the note (`audio/CaptureService.kt`)
- [ ] Mic cannot start or permission missing: error shown, nothing saved (`audio/CaptureService.kt`)
- [ ] Wake lock while recording and processing, max 1 hour, released when done (`audio/CaptureService.kt`)
- [ ] AI model warm-loads while you talk (skipped for types without AI cleanup) (`audio/CaptureService.kt`)
- [ ] Recording into an existing note ("addition") goes to the end of that note (`audio/CaptureService.kt`, `pipeline/VoicePipeline.kt`)
- [ ] Leftover recordings (app killed) are processed on next app start or Retry (`audio/CaptureService.kt`)
